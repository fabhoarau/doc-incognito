# AGENTS.md - doc-incognito

## What this project is

Local-first document anonymizer for French financial documents (PDF, images,
screenshots) before sending them to AI. 100% offline: no outbound network
calls, the API binds to 127.0.0.1 only. Personal data lives in `perso.txt`
(gitignored), tokenized as `[PERSO n]` before Presidio analysis; a guardrail
runs last and fails loudly if any personal entry survives.

## Stack

- Backend: FastAPI (`backend/app/`), Python 3.11-3.14 ONLY (presidio 2.2.366
  rejects 3.15+), venv at `backend/venv`, spaCy `fr_core_news_lg`, pymupdf,
  pytesseract + ocrmypdf/tesseract via Homebrew.
- Frontend: Vite 6 + React 18 + TS (`frontend/`). The dev server proxies `/api`
  to `http://127.0.0.1:8000`, so the UI uses relative URLs.

## Run

Docker (recommended, zero host install - single container, UI+API on 8000):

    docker compose up --build        # publishes 127.0.0.1:8000 only
    # perso.txt is bind-mounted read-only at /app/perso.txt, NEVER baked into the image
    # Dockerfile: node:22-alpine builds frontend/dist, python:3.12-slim-bookworm runs
    #   the API + apt tesseract-ocr(-fra)/ghostscript/poppler-utils + pip ocrmypdf + fr_core_news_lg


    # backend, port 8000
    cd backend && ./venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
    # frontend, port 5173
    cd frontend && npm install && npm run dev
    # UI: http://127.0.0.1:5173   |   API docs: http://127.0.0.1:8000/api/docs

In sandboxed environments the background-process tool can fail to spawn;
fall back to `nohup <cmd> > /tmp/doc-incognito-<name>.log 2>&1 & disown`.

## Test

    cd backend && ./venv/bin/pip install -r requirements-dev.txt
    cd backend && ./venv/bin/python -m pytest tests -q     # 37 tests (incl. security)
    cd frontend && npm test                                 # vitest, 17 tests
    cd frontend && npm run build                            # tsc --noEmit + vite build

## Layout

    backend/app/core/      config (pydantic-settings, ANON_ env prefix), analyzer singleton, French regex patterns
    backend/app/services/  business logic, shared by API and CLI (no duplication)
    backend/app/routers/   /api/anonymize, /api/redact, /api/files, /api/personal-data, /api/metadata/inspect
    backend/app/schemas/   pydantic models - frontend/src/types.ts mirrors them
    backend/scripts/       CLI entry points
    backend/tests/         pytest; conftest.py redirects perso.txt/uploads/output to tmp_path
    frontend/src/          App with 3 tabs: Anonymize, My personal data, Metadata check

## Conventions

- The user speaks French: answer in French. Code, comments, file names and
  commit messages stay in English.
- The UI is multilingual (i18n): ALL user-facing strings go through
  `frontend/src/i18n/` (`en.ts` is the source-of-truth Locale type, `fr.ts`
  mirrors it; `i18n.test.ts` enforces key parity). Never hardcode a label in a
  component. To add a language: new `<code>.ts` in `src/i18n/`, add it to
  `localeCodes` in `src/i18n/index.tsx`. Raw backend values (entity types,
  output labels, error messages) are mapped in each locale's `values` block
  with fallback to the raw value - the API contract stays English.
- Every commit ends with:
      Generated by Mistral Vibe.
      Co-Authored-By: Mistral Vibe <vibe@mistral.ai>
- Minimal diffs, match existing style, no emoji anywhere (code included).
- When a backend schema changes, update `frontend/src/types.ts` to match.

## Security invariants (do not break)

- `perso.txt`, `uploads/`, `output/` are gitignored: never commit them, never
  print perso.txt content into chat or logs.
- No outbound network calls; bind 127.0.0.1 only; CORS limited to the local
  Vite origin.
- Pipeline order matters: tokenize personal entries BEFORE Presidio analysis
  (longest entries first, `personal_data.tokenize`); the guardrail runs LAST,
  BEFORE any output file is written - on failure no file is produced and the
  leak values are masked server-side (`guardrail.mask_leak`). The image pipeline
  matches personal entries on the FULL OCR text (an entry can span several
  words) and has the same guardrail.
- `GET /api/files/{filename}` is confined to `output/` (resolve +
  `is_relative_to` + suffix allowlist + `Content-Disposition: attachment`).
  Raw uploads in `uploads/` are never served.
- Uploads go through `services/uploads.save_upload`: suffix allowlist, size cap
  (`ANON_MAX_UPLOAD_BYTES`, default 50 MB, 413 when exceeded), file name reduced
  to its final component, disk write off the event loop.
- Domain errors are `ValueError` -> 422 via a global handler in `main.py`
  (plus `PIL.UnidentifiedImageError` -> 422). CORS: local Vite origins only,
  explicit methods/headers.

## Known gotchas

- `PERSONAL_TOKEN` is `"[PERSO{}]"`, so tokens render as `[PERSO1]` (no space),
  even though README loosely writes `[PERSO n]`.
- pymupdf always reports a neutral `format` field in PDF metadata (not a leak).
- Presidio may re-anonymize the `[PERSO n]` token itself; the guardrail only
  verifies that the original entries are gone.
- Tests must never touch the real perso.txt: keep the autouse fixture in
  `backend/tests/conftest.py` that monkeypatches the settings paths.
